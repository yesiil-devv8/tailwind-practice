# Tailwind CSS Practice

Bu repoda HTML ve Tailwind CSS kullanarak yaptığım pratik çalışmalar yer almaktadır.  
Amacım front-end geliştirme becerilerimi geliştirmek ve yaptığım projeleri arşivlemektir.

## İçerik

- Katalog tasarımı
- Kart yapıları (Card Layout)
- Responsive grid sistemi
- Buton ve input tasarımları
- Fiyat hesaplama örneği (JavaScript)

## Kullanılan Teknolojiler

- HTML
- Tailwind CSS
- JavaScript (Temel)

## Amaç

Bu repo pratik yapmak için oluşturulmuştur.  
Yeni projeler eklenmeye devam edecektir.
